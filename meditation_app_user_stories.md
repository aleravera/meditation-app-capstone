# Meditation App User Stories

## Login and Registration

### User Story 1 - Registration
As a user, I want to register by entering my username, email, password, and country so that I can create an account and access the application.

### User Story 2 - Login
As a user, I want to log in using my email and password so that I can access my account.

### User Story 3 - Validation Feedback
As a user, I want to receive clear error messages when required fields are empty or my login details are incorrect so that I understand what needs to be corrected.

### User Story 4 - Persistent Account Data
As a user, I want my account information to be stored locally so that my data remains available between app sessions.

---

## Home Screen

### User Story 5 - Meditation Overview
As a user, I want to view available meditations on the home screen so that I can quickly choose a session that suits my needs.

### User Story 6 - Personalized Greeting
As a user, I want to see a personalized greeting on the home screen so that the app feels tailored to my account.

### User Story 7 - Quick Navigation
As a user, I want to access the menu, settings, and meditation details easily from the home screen so that I can navigate the app efficiently.

---

## Detail Screen

### User Story 8 - Meditation Details
As a user, I want to open a meditation and view its title, category, duration, and description so that I can understand what the session offers.

### User Story 9 - Return Navigation
As a user, I want to return easily from the meditation detail screen to the home screen so that I can continue browsing other sessions.

---

## Persistent Data

### User Story 10 - Save Preferences
As a user, I want my preferences to persist across sessions so that I do not have to configure the app every time I reopen it.

### User Story 11 - Save Theme
As a user, I want the app to remember whether I selected Light Mode or Dark Mode so that my visual preference remains consistent.

### User Story 12 - Save Reminder Settings
As a user, I want my notification and reminder preferences to be stored locally so that they remain active between sessions.

---

## External API Integration

### User Story 13 - Country Selection
As a user, I want to select my country from a list loaded from an external API so that I can enter accurate profile information during registration.

### User Story 14 - API Loading Feedback
As a user, I want to see a loading state while country data is being retrieved so that I know the app is processing my request.

### User Story 15 - API Error Recovery
As a user, I want to retry loading the country list if the API request fails so that I can continue registration without restarting the app.

---

## Settings Menu

### User Story 16 - Access Settings Menu
As a user, I want to open a settings menu from the home screen so that I can access account and application options easily.

### User Story 17 - Organized Menu Options
As a user, I want settings options to be organized with clear labels and icons so that I can quickly find the section I need.

### User Story 18 - Logout
As a user, I want to sign out from the settings menu so that I can securely end my session and return to the login screen.

---

## Settings Screen

### User Story 19 - Personal Information
As a user, I want to view and update my personal information so that my profile remains accurate.

### User Story 20 - Update Profile Data
As a user, I want to edit my name, username, age, and country so that I can keep my personal details up to date.

### User Story 21 - Theme Preference
As a user, I want to switch between Light Mode and Dark Mode so that I can use the appearance that is most comfortable for me.

### User Story 22 - Reminder Time
As a user, I want to set a specific daily reminder time so that I can choose when the app should remind me to meditate.

---

## Notifications

### User Story 23 - Enable or Disable Notifications
As a user, I want to enable or disable notifications globally so that I can control whether the app sends me reminders.

### User Story 24 - Select Meditations for Notifications
As a user, I want to choose which meditation sessions I receive notifications for so that reminders are relevant to me.

### User Story 25 - Select Notification Times
As a user, I want to choose Morning, Afternoon, or Evening notification periods so that reminders fit my daily routine.

### User Story 26 - Daily Reminder Time
As a user, I want to set an exact reminder time from the Notifications screen so that I can control when the reminder is sent.

### User Story 27 - Test Notification
As a user, I want to send a test notification so that I can confirm that browser notifications are working correctly.

### User Story 28 - Persistent Notification Preferences
As a user, I want my notification settings to remain saved after reopening the app so that I do not need to configure them again.
